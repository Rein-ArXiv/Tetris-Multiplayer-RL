# 합산 계약

한 출력 시각의 같은 채널을 더한다. Mixer.configure 형식과 PCM이 일치해야 한다.
start는형식과슬롯검사후에만교체한다. 자동슬롯선정/가로채기는없으며명시적9슬롯이다.
게인0에서도Voice를진행시킨다. stop_all후PCM해제,Player의retired잠금밖해제계약유지.

공통연산은nonfinite게인0/finite0..1,샘플별float곱후int32로0방향절삭.
보이스별기여량이정수로고정되므로오버플로없는합은순서독립이다. float합의결합법칙주장아님.
상한9*32768=294912,마지막에만int16범위제한. 보이스수/증폭정책변경시범위증명재검토.

렌더는전체출력0채움→최대256프레임씩512int16임시+512int32합→최종memcpy.
3KiB는두배열의크기이며전체스택측정아님. 출력미정렬/부분프레임꼬리처리,콜백할당없음.
기존Voice와Player콜백수명검사에새수치/블록검사를추가한다. 실제장치품질/지연보장은별개다.
