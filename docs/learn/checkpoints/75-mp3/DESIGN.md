# MP3 데이터 준비 계약

압축 바이트를 입력으로 삼아 인터리브 signed16 PCM을 소유 결과로 반환한다. 입력을 빌리는 drmp3는 입력 vector보다 먼저 종료한다. 초기화 성공 뒤에만 uninit 가드를 둔다.

load는 seek 가능한 로컬 경로용이다. 길이/입력 예산 확인 후 vector를 할당하고 정확한 읽기와 뒤의 EOF를 검사한다. 동시 작성 파일의 스냅샷 보장은 하지 않는다. FILE은 모든 경로에서 닫는다.

decode는4096샘플 임시 배열로 읽는다. 반환량은프레임, 붙일양은프레임*채널이다. 추가 전 남은PCM예산을 확인하고 초과하면 후보전체를버린다. 크기예산은논리출력이며capacity/일시재할당/내부디코더/장치변환을포함한전체메모리상한이아니다.

디코더는잘린파일의앞부분을반환할수있다. 0반환의원인을모두구별하지않으므로성공을파일전체무결성으로정의하지않는다. 빈결과는decode_failed. C++할당실패는allocation_failed,라이브러리초기화실패는decode_failed로표현할수있다.

단일헤더구현은mp3_decode.cpp하나에만정의한다. root와학습의공통로더는동일하고학습어댑터만Pcm16에연결한다. 장치·콜백·보이스수명은이모듈의책임밖이다.
