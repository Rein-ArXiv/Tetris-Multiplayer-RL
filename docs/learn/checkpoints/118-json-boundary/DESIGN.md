# JSON 경계의 계약

- 117의 스키마v5·서버 카탈로그·원자 구매·본인 선택을 유지한다.
- 전체 body는 1024바이트 이하, 원시 NUL 없이 하나의 평면 객체여야 한다.
- 중복 키는 이스케이프 해석 뒤 이름으로 파싱 도중 거절한다.
- 객체 크기는 요청별 필수 이름/타입 확인과 함께 적용한다.
- number는 비음수 uint64 정수만, text는 문자열만 전체 길이로 반환한다.
- 누락/다른 타입과 빈 문자열을 optional로 구별한다. 도메인 길이·문자·범위는 사용처가 검사한다.
- 문서가 파싱돼도 인증·가격·소유·잔액의 서버 판단이 필요하다.
- 파서 진단 본문은 로그에 출력하지 않는다. 콜백 중 DB를 수정하지 않는다.
- HTTP 수신 한도와 파서 한도는 같은 상수다. 반복 요청 예산과 공개 배포는 별도다.
- 실제 메타는 64KiB와 중첩 depth16, 학습 API는 평면1024바이트다.
- 실패 입력의 상태 무변경과 정상 대조 입력의 상태 변경을 함께 검사한다.
