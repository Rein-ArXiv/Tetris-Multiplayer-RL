# 아이콘 소유권의 계약

- 가격은 서버 카탈로그, 계정은 인증 키, 소유 여부와 잔액은 DB가 결정한다.
- 요청은 icon_id만 받는다. 가격·다른계정ID·소유목록을 추가하면 거절한다.
- 스키마v5유지. seed_shop은 신뢰된 서버 시작 시 icons참조행만 보충한다.
- inventory는 하나의SQL문장으로 프로필/선택/소유목록을 같은 스냅샷에서 읽는다.
- buy/choose는BEGIN IMMEDIATE 안에서인증·소유확인부터변경·응답조회까지수행한다.
- 구매는조건부차감1행+새소유권1행을함께커밋한다.실패/무시된삽입은전체롤백한다.
- 선택은본인소유일때만selected_icon_id를변경하며BP를차감하지않는다.
- 다른연결에서도한번만구매된다.기소유재구매409,동일선택재시도200.
- 구매응답유실은inventory로현재상태를확인한다.구매영수증/소비성반복상품은별도계약이다.
- fixture grant_icon/add_player는공개API가아니다.이미지파일의존재는소유증명이아니다.
