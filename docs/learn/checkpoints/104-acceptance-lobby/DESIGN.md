# 수락 로비의 구현 계약

- 단일 소유자가 두 파서와 준비 플래그를 변경한다. 객체는 복사·이동하지 않는다.
- 로비 진입 때의 시작 시각과 제한 시간을 유지하며, 활동은 마감을 늘리지 않는다.
- 호출자가 같은 단위의 단조 시각을 공급한다. time wrap이나 역행은 정상 입력이 아니다.
- READY는 한 바이트0/1, CANCEL은 빈 본문. 메시지 검증 후에만 상태와 알림을 만든다.
- 각 참가자는 첫 READY(1) 뒤 로비 제어 파싱을 끝낸다. 뒤의 완성/부분 프레임은 인계된다.
- accepted는 두 준비를 관측한 상태다. 통지 실패나 외부 종료는 인계 전 close로 중단한다.
- take는 accepted에서 한 번 성공한다. 소켓 두 개도 같은 호출자가 다음 소유자에게 넘긴다.
- FrameParser의 고정 배열은 std::move만으로 원본이 비워지지 않는다. 인계 경로에서 명시적으로 초기화한다.
- 로비와 각 parser의 메모리 상한은 프로세스·커널·후속 게임 단계의 총량을 뜻하지 않는다.
- unknown-before-ready 정책, 체크섬, 타이머 단위, 실제 신원과 seed 합의는 현재 서비스와 다르다.

누적 파일은 README/DESIGN/CMake 외 변경하지 않는다. 이전 단계의 버그 수정이 필요하면 별도 근거를 남긴다.
