# 재생 수명 계약

Player는 장치·PCM·Voice를 소유한다. SDL은 Player 주소를 빌리고 Voice는 PCM 주소를 빌린다.
Player는 복사/이동 금지다. 제어 API끼리는 메인 스레드에서 순차 호출한다.
Voice는 독립적으로 스레드 안전하지 않으며 원본은 연결 동안 생존·불변이어야 한다.

open 실패는 획득한 자원을 로컬에서 정리한다. 성공할 때만 멤버 소유권을 확정한다.
replace는 형식을 검사한 뒤 콜백과 배타적인 구간에서 대여 종료→PCM 이동을 수행한다.
형식 불일치는 후보를 이동하지 않고 기존 음원을 유지한다. 변환은 하지 않는다.

stop: 일시정지, Voice 분리·커서0, PCM 보존. unload: 그 뒤 PCM 해제, 장치 보존.
close: 잠금을 쥐지 않은 채 SDL_CloseAudioDevice로 콜백 종료 대기, Voice와 PCM 정리,
자신의 SDL 참조 반환. 소멸자에서 close를 호출한다.

finished는 마지막 프레임을 출력 버퍼로 복사한 상태다. 청취 완료와 구별한다.
출력은 먼저 전부0으로 채운다. 커서는 프레임 단위, 부분 프레임 요청의 나머지는0이다.
콜백에서는 할당/디코딩/파일 접근이 없다. 제어 경로의 PCM 파괴는 할당자 작업이므로
현재 잠금 방식은 실행 시간 상한을 보장하지 않는다. 게임 이벤트·다중 믹싱·볼륨·루프는 범위 밖이다.
