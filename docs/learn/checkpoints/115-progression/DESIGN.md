# 진행 수치의 계약

- RP는 기대 점수와 승패의 오차를 반영한다. K는 경기 전 RP로 각자 선택한다.
- 차감은 double 변환 뒤, RP 합은 int64_t에서 계산하고 0..INT_MAX로 포화한다.
- XP100/50, BP10/3. 무승부는 모든 수치를 유지한다. XP/BP 합의 넘침은 전체 실패다.
- XP 곡선의 단계 비용/누적 임계값은 같은 상수를 공유한다. 최대 레벨은 need=0이다.
- 표시용 음수 XP는0으로 정규화하지만 DB의 음수/타입 오류는 거절한다.
- v4는 careers와 match_progress를 추가한다. 기존 BP는 보존하며 과거 RP/XP는policy0/0값이다.
- put의 하나의 트랜잭션이 경기·두 BP·두 RP/XP·각 정산 내역을 확정한다.
- 재전송은 원래 진행 내역을 확인하며 현재 수치로 다시 계산하지 않는다.
- HTTP v2 policy는 BP정책 그대로. 로컬 progression_probe로 새 정산 내역과 현재 프로필을 조회한다.
- 학습용 fixture와 실제 인증/승자 판정은 별도 경계다. 운영의 별도 계정 DB에 적용하지 않는다.
