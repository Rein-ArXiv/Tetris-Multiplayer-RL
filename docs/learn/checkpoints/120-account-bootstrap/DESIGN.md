# 계정 부트스트랩 계약

- 119 누적 코드를 유지하고 계정 CLI·저장소·잠금·HTTP 어댑터·세션을 추가한다.
- Store는 애플리케이션 소유 로컬 폴더, 한 origin, 작업 전체의 cooperative lock을 소유한다.
- missing만 신규 발급 가능. 손상·다른 origin·읽기 오류는 중단하고 보존한다.
- 파일은 origin/player_id/token. 다른 계정은 덮지 않으며 동일 키 재저장은 허용한다.
- settings/private_file을 그대로 재사용한다. 원자적 교체·내구성 확인·잠금은 다른 계약이다.
- 세션은 메모리 pending 키와 origin·발급 시도 기록을 소유한다. 다른 origin으로 바꿀 수 없다.
- 저장 실패는 pending 유지/일반 인증 중단. retry는 동일 키만 저장한다.
- 온라인 프로필은 저장 후 조회 성공과 ID 일치 때만 결과로 반환한다. 키는 결과/로그로 보내지 않는다.
- 저장된 키의 거절·미확인은 신규 guest 발급으로 이어지지 않는다.
- 발급 미확인은 같은 세션 자동 재발급을 막는다. 프로세스 재시작까지 보존하는 저널은 없다.
- 콘솔은 blocking I/O 단일 worker. 게임 Tick에 직접 붙이지 않는다.
- 복구 코드·키 교체·공개 TLS·악성 같은 사용자 프로그램·원격 파일 시스템은 구현 범위 밖이다.
