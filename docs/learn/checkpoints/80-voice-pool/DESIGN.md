# 두 종류의 슬롯

Player의 PCM 배열은 음원을 소유한다. VoicePool의 보이스 배열은 PCM을 빌리고
각자의 커서를 가진다. owners_[voice]는 빌리는 음원의 슬롯 번호다.
한 owner에 연결하는 PCM은 stop_owner 이전까지 동일하고 생존/불변이어야 한다.
호출자는 모든 제어와 render 접근을 직렬화한다. Player는 SDL 장치 잠금을 사용한다.

VoiceOrder는 0..N-1의 순열을 유지한다. 성공한 시작의 번호를 끝으로 옮기므로,
모든 슬롯이 재생 중일 때 맨 앞이 가장 오래된 시작이다. 빈 슬롯이 있으면
순서와 무관하게 먼저 선택한다. 메모리와 연산량은 N=9로 제한된다.
이것은 가장 최근 접근을 갱신하는 LRU가 아닌 시작 순서 정책이다.

VoicePool은 PCM을 소유하지 않는다. stop_owner는 완료된 보이스의 참조까지 끊는다.
replace/unload가 한 음원에 연결된 모든 보이스를 분리한 뒤 retired PCM을 해제한다.
형식 거절은 기존 재생·소유자·순서를 유지한다. 풀 포화는 가장 오래된 재생을 끊는다.
음원 자리와 반환되는 일시적 보이스 번호는 세대가 있는 영구 식별자가 아니다.

네 종류의 준비된 삼각파는 각각 절댓값<=2000. 최대9개 중첩의 합은18000 이하.
효과음 종류와 동시 보이스 수를 독립적으로 다룬다. 규칙/사건 투영/main은79와 동일하며
Session이 사용하는 Player 구현을 통해 실제 게임의 재생 정책도 바뀐다.
