# 계정의 계약

- 공개 player ID와 128비트 난수 bearer token은 역할이 다르다.
- RAND_bytes 실패는 등록 실패이며 예측 가능한 값으로 대체하지 않는다.
- DB에는 목적별 SHA-256 해시만 저장한다. 클라이언트는 원문을 제시한다.
- v5 account_keys는 기존 fixture를 소급 인증 계정으로 만들지 않는다.
- 등록의 player/기본아이콘/wallet/career/hash는 하나의 트랜잭션이다.
- ID·해시 충돌만 후보를 다시 고른다. SQL/난수 오류는503이며4회상한을 둔다.
- /me는 헤더1개·정확토큰형식을 검사하고 토큰이 결정한 프로필만 반환한다.
- 키없음401과 구성손상503을 구별한다. LEFT JOIN의NULL을 타입검사로 거절한다.
- 원문은 발급 응답에만 있다. 프로필에는 자격증명이 없고 응답은no-store다.
- 등록의응답유실에는멱등보장이없다. 공개ID로분실키를복구하지않는다.
- Python진단도구는키를메모리에만유지한다. 실제클라이언트영속보관/복구는별도다.
