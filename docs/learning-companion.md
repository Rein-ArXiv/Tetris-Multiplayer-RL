# 프로젝트 동행 학습 화면으로 이동

[공개 강의 사이트](https://rein-arxiv.github.io/Tetris-Multiplayer-RL/) — 공개본은 1~55차시이며 이후 차시는 로컬 집필 중이다.

학습 가이드는 [HTML 학습 화면](learn/index.html)으로 옮겼다.
브라우저에서 목차·CS 설명·코드·실습·확인 문제를 함께 볼 수 있다.

작은 프로그램을 직접 확장하는 순서로 진행하고 기존 Part 문서는 참고 자료로 사용한다.
차시 끝의 객관식 문제는 선택 후 확인을 누르면 바로 정답과 해설을 제공한다.
다음 차시 첫머리는 핵심 개념과 구현 상태를 짧게 되짚는다.
로컬 집필본은 강의 본문, 객관식 문제·즉시 해설, 전체 학습 지도와 GPU 경로 미리보기를 제공한다.
작성된 차시와 집필 예정 차시, 원문 절별 대응 현황은 학습 지도에서 확인한다.

[여는 방법과 기록 저장 안내](learn/README.md)를 참고한다.
