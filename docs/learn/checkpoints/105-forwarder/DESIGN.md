# 방향별 포워더 계약

- A→B의 파서·부분 송신 위치와 B→A의 파서·부분 송신 위치는 독립적이다.
- 호출자는 각 방향을 직렬화하고, 접수한 바이트를 전달한 뒤에만 다시 읽는다.
- prefix를 채택할 때 원본을 비우고, 소켓 수신 전에 이미 모인 프레임부터 보낸다.
- 한 번의 flush는 하나의 논블로킹 송신 호출만 수행한다. 재진입·throw·무제한 대기는 금지다.
- pending을 다 보내야 다음 프레임을 준비하고, 다음 flush에서 그 프레임을 송신한다.
- would_block/interrupted는 진행0, 부분 성공은 정확한 offset 전진, 오류는 종료다.
- 소스의 프레임 경계 오류와 대상 송신 오류는 다른 진단이다. 어느 것도 승패가 아니다.
- EOF 때 완성/부분 프레임을 구별한다. 이 게임 실습은 반닫힘을 이용한 응답 배출을 지원하지 않는다.
- probe는 한 소유자가 두 방향을 공평하게 방문하며, 어느 한 방향이 끝나면 상대를 stop하고 소켓을 닫는다.
- 순수 객체의 메모리 제한은 커널 버퍼나 전체 연결의 제한이 아니다. 시간 예산은 호출자의 책임이다.
